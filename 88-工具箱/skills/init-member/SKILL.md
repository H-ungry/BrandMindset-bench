# init-member

## 什么时候用

本人电脑上只有克隆下来的公共区，还没有个人仓。整个项目里每个人只跑一次；重复跑不会覆盖已有部件。

## 怎么做

### 第一步：核对代号

在公共区 `01-成员名册/成员名册.md` 里找到本人那一行，取「代号」列的值，形如 `岗位（姓名）`。名册里没有本人，停下来，让本人去找统筹登记；不要自己往名册里加行。

### 第二步：确认私有远端

问本人个人仓的私有远端地址。本人不知道就不传 `--远端`，脚本会用默认的本地裸仓 `机房/远端/{代号}仓.git`。

### 第三步：跑脚本

在项目根目录（含 `公共区/`、`个人区/`、`机房/` 的目录）执行：

```
python 公共区/88-工具箱/脚本/init_member.py --代号 {代号} [--远端 {私有远端地址}]
```

脚本做几件事：在 `个人区/` 下建 `{代号}仓/`（独立 git 仓，五个目录 + `README.md` + `AGENTS.md`）；按名册设 git 身份（姓名取名册，邮箱 `p{n}@brand.local`）；挂上私有远端；装个人仓 `post-commit` hook（以后提交动了任务状态就自动同步工作台）；在公共区建 `00-推进管理/工作台区/{代号}.md` 与 `04-交换区/{代号}/{出件箱,收件箱}/`；最后把个人仓做首次提交。个人仓里已有的文件（如任务包）不删，纳入首次提交。

### 第四步：报结果

把个人仓路径、私有远端地址、git 身份、公共区里本人的工作台与两个盒子的路径逐条报给本人，然后带本人读个人仓 `AGENTS.md` 第一节，确认「我是谁」写对了。

## 输出格式

```
个人仓：个人区/{代号}仓/
私有远端：{地址}
git 身份：{姓名} / {邮箱}
工作台同步 hook：{代号}仓/.git/hooks/post-commit
工作台：00-推进管理/工作台区/{代号}.md
出件箱：04-交换区/{代号}/出件箱/
收件箱：04-交换区/{代号}/收件箱/
```

## 不做什么

不替本人登记名册；不建任务包；不动其他人的任何文件。
