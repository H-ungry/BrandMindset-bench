# fetch-task-inputs

## 什么时候用

在个人仓建任务包、要填 `输入清单.md` 的时候。这是任务的上下文闸：清单一次锁定边界，此后只读清单内的文件。

## 怎么做

### 第一步：从任务里抽检索词

从任务名、任务说明的目标句、上游协同单的事项与依据里，抽出三到六个检索词。用 `03-知识区/01-静态知识/术语与口径.md` 里的标准叫法。

### 第二步：查三本索引

| 查什么 | 去哪 | 取什么 |
| --- | --- | --- |
| 按事 | `00-推进管理/索引/关键词索引.md` | 检索词中标行给出的文件路径 |
| 按人 | `00-推进管理/索引/人物索引.md`，再进 `索引/人物/{代号}.md` | 对方岗位手里的口径、对方发过和收过的单据 |
| 按文件 | `00-推进管理/索引/文件索引.md` | 确认效力级，只取正本级与副本级 |

静态知识默认全读，动态知识按任务筛。草稿、`history/`、他人个人仓一律不取。来单附带的副本效力级是「副本」，接单时当对方的生效件读。

### 第三步：加个人知识

在本人 `01-输入/` 里挑与本任务相关的材料、笔记、口径。接到的材料副本也在这里。

### 第四步：出候选清单

逐条写成一行：路径、为什么要读它、效力级。交本人确认。

### 第五步：本人确认后定稿

确认过的条目写进 `02-任务/{任务名}/输入清单.md`。被划掉的条目不写。此后要读清单外的文件，先回来补清单。

## 输出格式

```markdown
# 输入清单

| 路径 | 为什么要读 | 效力级 |
| --- | --- | --- |
| 03-知识区/01-静态知识/项目目标.md | 本任务的验收标准挂在目标上 | 正本 |
| 04-交换区/{发起代号}/出件箱/副本-xxx.md | 来单附带的对方生效件 | 副本 |
```

## 不做什么

不替本人确认；不把清单外的文件顺手读了；不把正件复制进个人仓。
