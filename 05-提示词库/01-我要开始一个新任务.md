# 我要开始一个新任务

把下面整段复制给你的 AI，大括号里填任务名。任务名由本人定，跨人的任务来自收件箱里的协同单。

---

我要开始一个新任务：{任务名}。请按 `公共区/AGENTS.md` 与 `02-协作契约/任务包标准.md` 来做。

1. 在我的个人仓 `02-任务/{任务名}/` 建五件套：`任务说明.md`、`输入清单.md`、`待裁决事项.md`、`过程记录.md`、`工作产出/`，以及 `任务状态.yaml`（status 先写「未开始」）。
2. 若这个任务来自某张协同单，把 `任务状态.yaml` 的 `from` 写成那张单的路径。
3. 跑 `公共区/88-工具箱/skills/fetch-task-inputs/SKILL.md`：从任务名、任务说明、上游单里抽检索词，查三本索引，加上我 `01-输入/` 里的相关材料，出一份候选输入清单（路径 / 为什么读 / 效力级）给我确认。
4. 我确认后，把清单写进 `输入清单.md`，此后**只读清单内文件**；要读清单外的先回来补清单。
5. 写到 `工作产出/`，每个动作追加 `过程记录.md`；拿不准的记进 `待裁决事项.md` 并标「本人裁决」还是「跨人裁决」。

我确认输入清单前，不要动别的文件。
