# 我干完了要收工

把下面整段复制给你的 AI，每天收工时用。做完这四步才算收工。

---

我今天的工作收工了。请按 `公共区/02-协作契约/任务包标准.md` 的「收工三件套」和写回权限表做：

1. 更新我每个动过的任务包的 `任务状态.yaml`：状态改成对应枚举值，补 `outputs` 与 `updated`。要对外交的，先拿给我确认再升 `03-生效区/`（旧版移进 `04-归档区/`）。
2. 给每个动过的任务包追加 `过程记录.md`：日期、动作、结果、证据位置。
3. 写 `09-工作日志/{今天日期}.md`：今天推进了哪些任务、卡在哪、明天从哪继续。
4. 跑收工同步：提交个人仓并推送。个人仓 `post-commit` hook 会在本次提交动了 `任务状态.yaml` 时自动跑 `sync_desk.py`，把本人工作台从全部任务包的 yaml 重新生成、以本人身份提交并推送公共区；公共区推送后远端 `post-receive` hook 再重建看板与索引。手工兜底可跑
   `python 公共区/88-工具箱/脚本/sync_desk.py --代号 {我的代号} --日期 {今天日期}`

最后，把这次要我确认才写的收工内容（生效件、要投的单、要归集的件）逐条列给我，我点头后你再落盘、提交并推送。

注意：进度是自己走的——个人仓 `post-commit` hook 负责把工作台投影到公共区，公共区远端 `post-receive` hook 负责重建看板与索引；上面第 4 步的手动命令是兜底，hook 没跑起来就用它。
