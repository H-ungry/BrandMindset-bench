# 写回权限表

三层边界对人和 AI 同时生效。

## 自动写回（不用等谁点头）

| 对象 | 写者 |
| --- | --- |
| 本人个人仓 `02-任务/` 内的过程件：过程记录、待裁决事项、草稿 | 本人与本人的 AI |
| 本人个人仓 `09-工作日志/` | 本人与本人的 AI |
| 本人个人仓 `02-任务/**/任务状态.yaml` | 本人与本人的 AI（这是唯一上云的进度件）|
| 公共区 `00-推进管理/工作台区/{本人代号}.md` | 脚本 `sync_desk.py`，以本人身份从本人任务包生成 |
| 公共区 `00-推进管理/任务看板.html`、`索引/`、`通知台账/` | 脚本与 hook，协同系统身份 |

## 确认后写回（本人先点头，再由脚本或本人落盘）

| 对象 | 谁确认 |
| --- | --- |
| 个人仓 `03-生效区/` 升版 | 本人 |
| 交换区投递、回执、退回 | 发出人本人 |
| 知识区 `归集产出/current/` | 单据发起人验收通过后 |
| `00-推进管理/决策记录.md` | 统筹登记，决议提出人确认 |
| `公告栏.md` | 统筹 |

## 交换区的写法

- 出件箱只有箱主一个写者，正件与副本只落在发起人自己的出件箱。
- 收件箱只放指向消息，由投递脚本以发起人身份写入。这是交换区里唯一的他人写入，只写指向不写正件；隔离靠各人的 `AGENTS.md` 只指向自己的盒子。

## 禁止写回

- 他人的个人仓、他人的出件箱、他人的工作台文件；他人的收件箱只能经投递脚本写指向消息。
- 治理文件：`README.md`、`AGENTS.md`、`01-成员名册/`、`02-协作契约/`、`03-知识区/01-静态知识/`，这些只有统筹能改。
- 密级口径：**商户预算金额、商户 ROI 数值**的具体数值，任何公共文件都不写；**泛品牌词全表**不在公共区留副本。
- 绕开脚本手工在交换区或工作台区新建、改名、删除文件。
