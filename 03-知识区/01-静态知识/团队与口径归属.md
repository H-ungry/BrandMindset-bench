# 团队与口径归属

## 一、五侧职责

- **产品侧**：口径与商业化闭环。
- **算法侧**：泛品牌词与语义能力。
- **数据侧**：指标生产与追溯。
- **研发侧**：链路与报告承接。
- **运营/销售侧**：品牌方沟通与预算承接。

## 二、谁手里有什么口径

| 口径 | 掌握者 | 可见范围 |
| --- | --- | --- |
| 全盘方案与指标口径 | 商业化产品（本人）| 公共 |
| **商户预算金额** | 行业业务运营（林嘉）| **密级：公共区只写"由行业业务运营掌握"，不写数值** |
| **泛品牌词全表** | 算法AI团队（周衍）| **资产隔离：公共区只写"由算法掌握"，不附全表** |
| **商户 ROI 数值** | 数据产品（许宁）| **密级：公共区只写"由数据产品掌握"，不写数值** |
| 链路与接口 | 平台后端研发（高远）| 公共 |
| 页面与埋点 | 前端报告研发（苏晴）| 公共 |
| 验收标准 | 测试质量（钱峰）| 公共 |
| 商户预算反馈 | 销售客户成功（郑昊）| 公共 |

## 三、密级与资产隔离（写回边界）

- **密级两类**：商户预算金额、商户 ROI 数值——任何公共文件不写数值，只写指向；要数值走协同单找掌握者。
- **资产隔离一类**：泛品牌词全表只在算法侧，公共区不附全表（理由：可复制的项目资产 + 全表落公共区会污染上下文，非保密）。
- 别人要用掌握者的口径，走协同单；掌握者不在公共区留数值副本。

## 四、外圈

品牌商（投手）、用户不进工作区，只消费投后报告与看板。
