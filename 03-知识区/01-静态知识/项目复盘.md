# 项目复盘

## 一、项目 STAR

**S 背景**：品牌广告主不缺品牌经营预算，真正的问题是预算投出去后很难证明效果。旧指标（曝光/点击/CTR/标准品牌词搜索量）很难说明是否沉淀为品牌心智；真实心智不只表现为搜标准品牌名 → 效果被低估，站外种草到站内的回搜/回店/回购链路也不完整。

**T 任务**：建立一套**可量化、可追踪、可复盘**的品牌新力度量，以 **180 天泛品牌主动回搜**和**品牌回购**为核心指标；把品牌广告从「曝光点击复盘」升级为「主动回搜、回购和预算承接复盘」。

**A 动作**：四层推进（详见 `动作分解.md`）：①扩展识别关键词 ②定义意图回搜口径 ③建设 AI 全域追踪与回收 ④接入商业化链路。

**R 结果**：B 组品牌相关 query 识别覆盖度 61.8%→77.9%（较 A 组 +16.1pp）、返回词有效率 +7.7pp、跨品牌误命中率 -1.4pp；广告消耗 +6.6%、广告 GMV +9.7%、ROI 2.72→2.80，大盘 GMV -0.5%、自然搜索 CVR 跌幅 1.0%、badcase 1.26% 均未破线；供给侧预算净增率 +6.5%、承接率 81.2%、年化空间约 0.84 亿。

## 二、经验（5 条）

1. **从预算问题出发，不从技术能力出发**：AI 扩词、GRPO、全域追踪都是手段，真正要解决的是广告主为什么不持续加投。
2. **区分核心商业结果与模型过程指标**：预算/消耗/GMV/ROI/大盘是结果；覆盖率、准确率是过程支撑。
3. **AI 结果不能直接上线，必须配治理机制**：生命周期 + 人工复核 + 异常回滚 + 持续纠错。
4. **AB 对象必须和产品改动点一致**：按请求流量分桶，不按商家。
5. **避免过度归因**：说「提升了投后解释力、趋势对比能力和预算承接能力」。

## 三、难点（3 个）

1. 容易写成「AI 扩词项目」而非「品牌广告预算释放项目」——要把主线从「识别更多词」拉回「为什么广告主愿意释放预算」。
2. 口径越写越复杂，但老板和广告主要能理解、能相信、能用——**对内严谨、对外可解释的双层表达**。
3. 难判断哪些数据是核心结果、哪些只是过程支撑——主线先讲业务结果，再用过程指标补充。

## 四、优化点（5 个）

1. 提升站外回流完整性（统一跳转参数，提升 source/content_id/jump_id/brand_id 完整率）。
2. 优化 GRPO 反馈机制（把审核通过率、成交回搜表现纳入正向激励）。
3. 完善品牌新力诊断分层（高回搜高爆 / 高回搜低爆 / 低回搜高爆 / 低回搜低爆）。
4. 从投后复盘前置到投前策略。
5. 建立更完善的类目对标基准。
