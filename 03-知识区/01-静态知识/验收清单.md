# 上线前必须走通的业务过程（验收清单）

> 把项目**上线前必须端到端跑通的场景**逐条列出，并写清**每个场景必须看到的结果**。它是研发/测试的「能上线」客观标准，也是任务验收的依据。

| 验收过程 | 必须看见的结果 |
| --- | --- |
| 输入一个标准品牌词，走泛品牌词识别 | 返回泛品牌候选词，并**标注每个候选的召回原因** |
| 输入依据不足的商品/品牌 | 返回**「信息不足/不生成」及原因**，不扩写不存在的事实 |
| 产生一次回搜 | 能从日志**回溯**到触达时间与最近一次有效触点 |
| 已失效的优惠/旧文案 | **停止展示**，旧承诺不出现在报告与页面 |
| 生成投后报告 | 能按 **5 维拆解**（内容/渠道/人群/关键词/商品系列）并给出**诊断建议** |
| 全量跑风险护栏 | **CVR 跌幅 ≤ 2%、badcase 率 ≤ 1.5%、广告消耗提升 ≥ 5%** 均未破线 |

> 本清单落地到具体任务时，作为对应任务包 `任务说明.md` 的验收标准。
