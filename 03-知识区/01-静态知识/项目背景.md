# 项目背景

> 依据：课件《实战 6 阿里电商品牌广告新力度衡量》完整版。数据口径以完整版为准。
> 本项目按公司内网协同环境的运转方式搭建；业务口径以课件「完整版」为准，不逐条对齐真实阿里项目。

## 1. 项目概述

| 项 | 内容 |
| --- | --- |
| 组织位置 | 中国电商事业群 - 阿里妈妈营销平台 - 商业化运营中心 - 品牌广告产品 - 品牌组 |
| 业务问题 | 品牌广告投放过程，**缺少过程指标** |
| 项目定位 | 建立一套**从消费者心智出发**的品牌广告效果评估体系（「品牌新力」）|

## 2. 项目背景

### 2.1 广告主调研：品牌预算并不缺，核心卡点是品牌效果无法被客观衡量
品牌广告主预算充足，但品牌广告效果无法被客观衡量，导致品牌广告预算被削减。

### 2.2 业务洞察：淘系具备品牌经营闭环，但缺少可量化、可追踪的品牌力标尺

- 淘系有店铺、会员、内容、直播等完整的品牌经营闭环，品牌商愿意在这里做长期经营。
- 但品牌广告预算正在被内容平台分走：CPT 预算先给小红书、抖音，剩余才轮到淘宝；品牌商需要一把能说明「站外种草 → 站内回搜 → 回购」的尺子。
- 现有指标只能证明曝光、点击和标准品牌词搜索量，无法说明是否沉淀为品牌心智，品牌力因此被系统性低估。

### 2.3 数据洞察：口径存在间断与理解歧义，是品牌力指标无法统一的根本原因

- **词口径不全**：只覆盖用户准确输入标准品牌名的行为，系列词、品类关联词、产品特性词、消费者昵称等泛表达未被识别。
- **链路间断**：站外种草到站内的回流未打通，来源、内容品牌、品牌对齐、用户对齐四件事缺数据。
- **归因未去重**：同一用户跨渠道下单未归并，广告 GMV、ROI 虚高，商户自己能感知，指标因此不被信任。

### 2.4 结论及 Idea
核心 idea：**建立一套科学的品牌广告效果评估体系，从消费者心智的角度，全面评估品牌广告的效果。**

## 3. 为什么选品牌商做突破口

- 一个品牌商点头的预算比一堆中小商户加起来还多；头部联系密切、画饼概率低。
- 痛点明确 → 解决后效果好 → 形成案例 → 推广说服腰部。
- 试点选择：头部需求高 + 历史表现好 + 痛点明确（120 个头部品牌/厂商）。
- **提前告知品牌商**：品牌商按季度批预算、走审批流程；上线后才知会要等一个月。
