# 术语与口径

> 统一叫法的正本。写任何文件用这里的标准叫法，不要自己造词。

## 一、广告业务指标

| 缩写 | 全称 | 中文 | 计算/说明 |
| --- | --- | --- | --- |
| PVR | Page View Rate | 广告请求占比 | 广告请求数 / 大盘总请求数（约 85%）|
| ASN | Average Show Number | 平均每条请求广告数 | 广告总曝光数 / 广告请求数（约 3.05）|
| CTR | Click-Through Rate | 点击率 | 广告点击数 / 广告曝光数 |
| CVR | Conversion Rate | 转化率 | 成交订单数 / 广告点击数 |
| C×R | CTR × CVR | 用户体验核心指标 | 跌幅 ≤ -2% 为红线 |
| CPM | Cost Per Mille | 千次展示成本 | 广告消耗 / 曝光 × 1000 |
| CPC | Cost Per Click | 单次点击成本 | 广告消耗 / 点击数 |
| CPS | Cost Per Sale | 单次成交成本 | 广告消耗 / 成交订单数 |
| CPT | Cost Per Time | 按时长计费的合约广告 | 品牌内容型广告常见，按周期售卖（90~180 天）|
| Ad Load | Ad Load | 广告密度 | 广告曝光数 / 大盘总曝光数 |
| GMV | Gross Merchandise Volume | 商品交易总额 | |
| ROI | Return on Investment | 投资回报率 | 广告带来的 GMV / 广告消耗 |
| eCPM | expected Cost Per Mille | 千次曝光预估收益 | 1000 × pCTR × gspBid |
| gspBid | generalized Second-Price Bid | 实际扣费（二价）| 下一名商户 Bid × 质量分 + 0.01，≤ 商家 Bid |
| pCTR | predicted CTR | 预估点击率 | |

## 二、AI 指标

| 缩写 | 全称 | 在项目中的作用 |
| --- | --- | --- |
| BERT | 双向 Transformer 编码器 | 语义召回，挖掘候选泛品牌词 |
| SFT | 监督微调 | 让模型学习人工审核标准（候选词排序）|

## 三、项目专有口径

| 术语 | 定义 |
| --- | --- |
| 品牌新力 | 回搜 + 回购构成的品牌力评分，本项目核心指标 |
| 主动回搜 | 用户真正想起品牌后的主动搜索；**排除**广告点击、推荐点击、跳转、诱导搜索 |
| 回购 | 对相同商品二次购买，排除退款/取消 |
| 180 天窗口 | 归因窗口；品牌广告看中长期（CPT 按 90~180 天卖），太长商户不接受 |
| 有效品牌落点 | 搜索后进入能承接品牌经营的页面（排除进竞品店）|
| 触点优先级 | 以触达时间为起点向后观察，优先归因最近一次有效触点 |
| 泛品牌词 | 系列词、品类关联词、产品特性词、消费者昵称/俗称等非标准品牌表达 |
| 去重 | 同一用户短期多次搜/跨端重复买/分享再下单归为一单；CVR 最高为 1 |
