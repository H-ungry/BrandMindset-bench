# 项目目标

## 一、目标（四层）

| 层级 | 内容 |
| --- | --- |
| 核心商业目标 | **提升品牌广告收入** |
| 收入空间测算 | 品牌广告收入提升空间巨大（保守测算区间 **0.79 亿 ~ 1.27 亿**）|
| 机制目标 | 建立一套**品牌预算释放的评估机制** |
| 长期目标 | 升级品牌广告的**优化目标与复盘口径** |

## 二、三层指标

| 层级 | 内容 |
| --- | --- |
| 目标指标 | 北极星指标 → 业务指标 → 项目目标 |
| 过程指标 | 动作 → 过程指标的映射 |
| 风险指标 | 用户体验（C×R 跌幅 ≤ -2%）、商户体验（ROI 不下降）|

## 三、口径边界

- 品牌新力是**投后解释力、趋势对比与预算承接**的指标，不把每一次回搜/回购都严格归因到广告。
- 策略归因增量只占 **5~8%**（预算主要是运营拉来的功劳）；供给拉动收入远大于策略。
- 目标怎么落到分工：见 `动作分解.md` 与 `00-推进管理/当前推进.md`。
