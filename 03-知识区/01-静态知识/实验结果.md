# 实验结果

> 数据口径以课件完整版为准。

## 一、AB 设计

- 对象：**用户搜索/回流请求**；按用户/设备 ID 稳定分桶，统计落到 `request_id`。
- **ABC 分桶的是请求流量，不是品牌广告主**（改动发生在搜索链路的 query 识别、返回词、排序、回收）。
- 分组：A（原逻辑）/ B（泛词召回，排序不变）/ C（泛词召回 + 排序优化 + 归因承接）。

## 二、供给侧

- 可影响**预算净增率 +6.5%**。
- **续投率** 39.6% → 47.4%；**加投率** 8.7% → 15.1%。
- **新增预算消耗承接率 81.2%**。
- 季度新增广告消耗 0.21 亿 → 年化约 **0.84 亿**（落在 0.79~1.27 亿内）。
- 分型：高回搜高爆款（预算与加投最高）/ 高回搜低爆款（要同步修商品价格落地页）/ 低回搜高爆款（先调内容与泛词承接）。

## 三、流量侧

| 指标 | 结果 |
| --- | --- |
| 品牌相关 query 识别覆盖度 | 61.8% → **77.9%**（B 组）|
| 请求返回词有效率 | → **86.1%**（C 组）|
| 低相关词跨品牌误命中率 | → **2.2%** |
| 广告消耗 | **+6.6%**（C vs A）|
| 广告 GMV | **+9.7%** |
| ROI | 2.72 → **2.80** |
| 广告曝光 PV | **+12.5%** |
| 品牌广告 CTR | **+0.32pp** |
| Ad Load | **+1.0pp** |

大盘风险：大盘 GMV -0.5%；自然搜索 CVR 跌幅 1.0%；搜索相关性 badcase 1.26% —— 均未破线。

## 四、模型指标（过程支撑）

品牌主体资产覆盖率、词审核通过率、BERT 候选词有效率、GRPO 准入准确率、正式词污染率（2.2%）。
> 作用：解释「结果为什么可信」；核心仍是预算释放、广告消耗、GMV、ROI 与大盘风险。

## 五、扩量

C 组 10% → 30% → 50%；继续放量条件：**CVR 跌幅 ≤ 2%、badcase ≤ 1.5%、广告消耗提升 ≥ 5%**。
