# 词资产现状梳理 · 中期结论

> 2026-09-09 出稿。给消费侧三家人：统筹（AI 对接规划）、苏晴（投后报告）、高远（日志链路）。
> 红线：泛品牌词全表不入本仓，本文只给分类、占比口径与结论。

## 一、词层五分类（定稿）

| 词层 | 界定 | 线上覆盖 |
| --- | --- | --- |
| 标准品牌词 | 品牌官方注册名 | 全覆盖（规则词表） |
| 系列词 | 品牌下产品系列名 | 约八成，新系列滞后 1~2 季度 |
| 品类关联词 | 品类词 + 品牌暗示组合 | 极少 |
| 产品特性词 | 功能/成分/卖点表达 | 几乎无 |
| 消费者昵称 | 社区黑话、缩写、错拼 | 无 |

## 二、识别现状

- 线上规则词表命中逻辑为**完全等值**，连「品牌名+旗舰店」这类后缀变体都不命中，口径比业务预期紧。
- 去年一版语义召回模型未上线，本次回测（任务包「模型准确率回测」）正在补齐它的真实水位。

## 三、回测第一批初步数（千级金标，标注进行中）

| 词层 | 规则词表 | 语义模型（初步） |
| --- | --- | --- |
| 标准品牌词 | ≈100% | ≈100% |
| 系列词 | ≈80% | ≈90% |
| 品类关联词 | <5% | ≈60%（分歧样本多，待仲裁） |
| 产品特性词 | ≈0% | <40%（初标，置信低） |
| 消费者昵称 | ≈0% | <40%（初标，置信低） |

> 初步数的口径：单人初标未仲裁，只用于消费侧定方向；正式数以全量回测为准。

## 四、消费侧建议

1. **指标口径（统筹）**：泛词补入后回搜基数会显著变大，指标必须分层定义（标准词回搜 / 泛词回搜），不能合并成单一口径。
2. **投后报告（苏晴）**：建议按词层分两行展示，品牌力增长故事主要在泛词层，合并展示会抹平。
3. **日志链路（高远）**：若泛词识别上线上模型，日志需新增「识别词层」字段，历史回溯要预留双跑期。
4. **维护权（待裁决）**：词表更新滞后 1~2 季度是实测，维护权归属已挂统筹待裁决。
