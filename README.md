# 品牌新力 · 多人协同工作区

「品牌新力」广告项目（阿里电商品牌广告新力度衡量）的多人协同工作区。项目全部过程以文件承载：人各在自己的**个人区**推进，产物经确认后投进**公共区**交换区，消费方回执确认才归集进公共区知识区。

工作区以人组织：**8 名成员**，每人一个代号，形如 `岗位（姓名）`，每人一个**独立个人仓**（各自带私有远端）、一对交换区盒子、一份工作台。

## 两个区（双仓）

| 区 | 装什么 | 是 git 仓吗 |
| --- | --- | --- |
| `公共区/` | 共识知识、协作契约、交换区、推进管理 | **一个 git 仓**，远端 = `机房/公共区.git` |
| `个人区/` | 每人的私人工作区（材料、任务包、草稿、生效件、日志）| **每人一个独立 git 仓**，各自私有远端 `机房/远端/{代号}仓.git` |

> 双仓：公共区一个共识仓，**每人一个个人仓**。个人仓是独立仓、各自有私有远端，本仓内容别人看不到；公共区只放**共识过、大家公认**的知识。

## 目录路由（公共区）

| 目录 | 装什么 | 什么时候来 |
| --- | --- | --- |
| `00-推进管理/` | 当前推进、决策记录、任务看板、每人的工作台、通知台账、三本索引与每人一份的人物文件 | 想知道项目走到哪、谁找我、我手头有什么、某个人干了什么 |
| `01-成员名册/` | 8 名成员的职责、对接与口径归属，以及角色-目录-审核映射 | 想知道某件事该找谁、某个口径在谁手里 |
| `02-协作契约/` | 命名规范、任务包标准、写回权限表、八件模板 | 起草任何协作文件之前 |
| `03-知识区/` | 静态知识（项目背景、目标、术语口径、系统图景、团队口径归属、动作分解、里程碑、实验结果、复盘、验收清单）与动态知识（会议、归集产出）| 要查项目口径与已生效结论 |
| `04-交换区/` | 每人一个出件箱与一个收件箱 | 要给别人派活、或者查别人派给我的活 |
| `05-提示词库/` | 四份按场景写好的提示词，整段复制给自己的 AI | 不熟悉 AI 又要开工 |
| `88-工具箱/` | skills、脚本、hook、经验库 | 执行任何协作动作 |
| `99-归档/` | 按阶段冻结的只读切片 | 回看某个阶段当时的状态 |
| `公告栏.md` | 统筹对全员的公告（模拟版才有，正式由通知直推）| 看阶段切换与口径冻结 |

## 运行机制（双仓）

- **公共区**：一个 git 仓，远端是 `机房/公共区.git`；只放共识知识、协作契约、交换区、推进管理。
- **个人区**：每人一个**独立 git 仓**，各有私有远端 `机房/远端/{代号}仓.git`；本人的材料、草稿、生效件、日志只在本仓，别人看不到。
- **进度链只有一条**：个人仓 `任务状态.yaml` 是唯一来源 → 个人仓 `post-commit` hook 跑 `88-工具箱/脚本/sync_desk.py`，把本人工作台重新生成、**以本人身份**提交并推送公共区 → 公共区远端 `post-receive` hook 再重建看板与索引。
- 人只改自己任务包里的 `任务状态.yaml`，**不手改**工作台与看板。

## 新手三步

1. 克隆公共区到自己的电脑，在 `01-成员名册/` 里找到自己的代号。
2. 打开 `05-提示词库/00-我是新人第一次用.md`，把代号填进去，整段复制给自己的 AI。AI 会为你建**个人仓并挂私有远端**，并在公共区配好工作台与收发件箱。
3. 跟着 AI 走完第一遍读取链：规程、目录、背景与目标、名册里的自己、当前推进、谁找我。

AI 的入口是 `公共区/AGENTS.md`，不走本文件。
